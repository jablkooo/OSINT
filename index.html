👤 Sociální sítě a uživatelská jména 4

Sherlock CLI

Stopování digitální stopy uživatelů napříč stovkami sociálních sítí.

sherlock prezdivka

Maigret CLI

Extrémní verze Sherlocka – hledá profily podle uživatelského jména.

maigret cilova_prezdivka

WhatsMyName WEB

Vyhledává uživatelská jména na stovkách webů.

whatsmyname.app

Blackbird CLI

Vyhledávání uživatelských jmen a e-mailových stop.

python blackbird.py --username johndoe

📧 E-maily a identity 3

Holehe CLI

Na jakých internetových službách a sociálních sítích je registrován konkrétní e-mail.

holehe cilovy-email@gmail.com

theHarvester CLI

Mapování firemní infrastruktury, sběr uniklých e-mailů a jmen zaměstnanců.

theHarvester -d nazevfirmy.cz -b linkedin

Blackbird CLI

Hledání e-mailových stop a generování PDF reportu.

python blackbird.py --email johndoe@example.com --pdf

🌐 Domény, weby a servery 6

Photon CLI

Hloubkový průzkum webových stránek – crawluje URL, e-maily, účty.

WHOIS CLI

Zjištění majitele domény a registračních údajů.

whois seznam.cz

DIG CLI

Průzkum DNS záznamů a skrytých serverů.

crt.sh WEB

Vyhledávání TLS/SSL certifikátů a odhalení subdomén.

crt.sh

Wayback Machine WEB

web.archive.org

SpiderFoot TOOL

github.com/smicallef/spiderfoot
